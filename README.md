# Hide in Plain Sight
## Build Your Own Steganography Tool with AI

In this workshop, you'll use AI-assisted coding to build a browser-based
steganography tool that can hide secret messages inside PNG images.

By the end of the workshop, you'll have:

- A working steganography web app
- A customized version of the project
- A GitHub project you can share
- A project you can showcase on your AWS Builder Center profile

---

# What You'll Need

- A laptop
- A modern web browser
- An AWS Builder ID
- Access to an AI coding tool

No Python, Node.js, or other software installations are required.

---

# Workshop Roadmap

## Part 1 — Create Your AWS Builder Account

1. Create your AWS Builder ID
2. Set up your Builder Center profile
3. Claim your Builder Center alias

---

## Part 2 — Build the Base Project

We'll first create the core steganography application.

The app should allow you to:

- Upload a PNG image
- Enter a secret message
- Hide the message inside the image
- Download the encoded image
- Upload an encoded image
- Recover the hidden message

Open:

`prompts/part-1-build.md`

Copy the provided prompt into your AI coding tool.

---

## Part 3 — Run Your Project

Your project should contain:

index.html
style.css
script.js

Open `index.html` in your browser.

Test:

1. Upload the sample PNG
2. Enter a secret message
3. Encode it
4. Download the new PNG
5. Upload the encoded PNG
6. Decode the message

---

## Part 4 — Make It Yours

Now customize your project.

Do NOT simply copy someone else's finished design.

Choose:

- A visual style
- At least one new feature
- A project name

Open:

`prompts/part-2-customize.md`

Use the prompt template to create your own customization prompt.

---

## Part 5 — Test Your AI-Generated Code

Try to break your application.

Test:

- A normal message
- A long message
- Emojis
- An empty message
- A very small image
- The wrong file type
- Decoding an image with no hidden message

If something breaks, ask your AI assistant to diagnose and fix it.

---

## Part 6 (Optional) — Publish to GitHub

Create a new GitHub repository.

Upload:

- index.html
- style.css
- script.js
- README.md

Optional: Enable GitHub Pages so your project becomes a live website.

---

## Part 7 — Showcase Your Project

Add your finished project to your AWS Builder Center profile.

Include:

### Project Name
Example: GhostPixel

### Description
A browser-based image steganography tool that hides text inside PNG images
using least-significant-bit encoding.

### Technologies
HTML, CSS, JavaScript, Canvas API

### What I Learned
- Basic steganography concepts
- Image pixel manipulation
- AI-assisted development
- Testing AI-generated code
- Front-end web development
